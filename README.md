# Louco Hub — auditoria estática

Este repositório contém a documentação da revisão estática de um script Lua enviado para análise. O script original **não foi adicionado nem executado**: ele automatiza ações em jogo por APIs de executor, manipula remotes e contém verificações anti-detecção.

## Documentação

- [Auditoria estática do script e das referências externas](docs/auditoria-estatica.md)

## Escopo e segurança

- Nenhum script remoto foi executado.
- Os três arquivos de texto no GitHub foram consultados apenas como texto; o módulo protegido por Luraph foi tratado como opaco.
- Não foram reproduzidas nem reconstruídas funções de exploit, automação de jogo ou evasão de detecção.
- As conclusões são limitadas ao conteúdo disponível durante a auditoria; referências remotas podem mudar com o tempo.
